01 LA PHRASE

Une phrase simple ou plusieurs propositions

Une phrase commence par une majuscule et se termine par un signe de ponctuation. Elle peut informer, questionner, donner une consigne ou exprimer une émotion. Une phrase simple contient un verbe conjugué ; une phrase plus longue peut en contenir plusieurs : « Le soleil se couche et les oiseaux rentrent. »

02 LES CLASSES DE MOTS

Nom, déterminant, adjectif et verbe

Le nom désigne ; le déterminant l’accompagne ; l’adjectif précise le nom ; le verbe dit l’action ou l’état. Des pronoms peuvent remplacer un nom. Des mots comme « dans », « avec », « puis » ou « souvent » relient ou précisent la phrase.

ON IDENTIFIE LES MOTSCes petits oiseaux chantent.

« oiseaux » est le nom, « ces » le déterminant, « petits » l’adjectif, « chantent » le verbe.

03 LES ACCORDS

Le nom commande les accords

Le déterminant et l’adjectif s’accordent avec le nom en genre et en nombre : « un grand arbre », « des grandes branches ». Le verbe s’accorde avec son sujet : « l’oiseau chante », « les oiseaux chantent ».

04 LES COMPLÉMENTS

Préciser le verbe et l’action

Le COD répond souvent à « qui ? » ou « quoi ? » après le verbe : « Elle observe quoi ? les oiseaux. » Des compléments circonstanciels donnent le lieu, le moment ou la manière : « dans le jardin », « ce matin », « doucement ». On commence aussi à observer les groupes introduits par une préposition et à repérer ce qu’ils complètent.

05 LES TEMPS DES VERBES

Présent, imparfait, futur et passé composé

Le présent raconte ce qui se passe ou une habitude ; l’imparfait décrit une situation passée ; le futur annonce ce qui arrivera ; le passé composé raconte une action terminée. Dans les récits, on peut rencontrer le passé simple à la lecture : « Le héros entra dans la grotte. » Il suffit d’abord de le reconnaître.
