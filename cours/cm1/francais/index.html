01 LA PHRASE

Repérer le verbe et son sujet

Une phrase simple contient un verbe conjugué. Une phrase complexe en contient plusieurs : « Le vent souffle et les feuilles tombent. » Pour trouver le sujet, demande « Qui est-ce qui… ? » ou encadre-le avec « C’est… qui ». Le verbe s’accorde avec son sujet, même si d’autres mots les séparent.

02 LES CLASSES DE MOTS

Reconnaître la nature des mots

Le nom, le déterminant, l’adjectif, le pronom et le verbe sont des classes de mots variables : leur forme peut changer. Une préposition comme « dans » ou « avec », un adverbe comme « vite » et une conjonction comme « mais » sont invariables. La nature indique ce qu’est le mot ; sa fonction indique son rôle dans la phrase.

03 LE GROUPE NOMINAL

Enrichir le nom

Dans un groupe nominal, le nom principal est accompagné d’un déterminant. Un adjectif peut le préciser : « le chien rapide ». Un complément du nom, souvent introduit par une préposition, apporte une autre précision : « le chien de ma voisine ». Le groupe nominal peut occuper plusieurs fonctions dans la phrase.

ON ENRICHITun vélo → un vieux vélo de course

« vieux » est un adjectif ; « de course » est un complément du nom.

04 LES COMPLÉMENTS

Compléter le verbe ou préciser l’action

Le COD complète directement le verbe : « Elle range ses livres. » Le COI est introduit par une préposition : « Il parle à son frère. » Les compléments circonstanciels indiquent notamment le lieu, le temps ou la manière : « dans la classe », « ce matin », « avec soin ». Certains compléments peuvent être déplacés ou supprimés sans rendre la phrase incorrecte.

05 LES TEMPS DES VERBES

Conjuguer selon le moment du récit

Au présent, le verbe exprime ce qui se passe maintenant ou une habitude ; le futur simple annonce une action à venir ; l’imparfait décrit ou raconte une habitude passée ; le passé composé présente une action passée et terminée. À la lecture, tu peux aussi rencontrer le passé simple, surtout dans les récits : « Le chevalier entra. »

06 À TOI DE JOUER

Vérifie ce que tu as retenu

2 Dans « Le chien de Lina aboie », quel groupe est le sujet ?
3 Dans « un grand bateau », quel mot est l’adjectif ?
4 Dans « la cabane de bois », quel groupe complète le nom ?
5 Quel groupe est COD dans « Tom prépare un gâteau » ?
6 Dans « Nous parlons à notre maîtresse », quel groupe est COI ?
7 Dans « Demain, ils visiteront le musée », le verbe est…
8 Dans « Les enfants jouent dans la cour », quel groupe indique le lieu ?
